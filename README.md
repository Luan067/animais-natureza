# 🐾 Animais da Natureza

Projeto front-end desenvolvido com **HTML, CSS e JavaScript puro**, focado em prática de **arquitetura modular, animações de interface e consumo de APIs com fetch**.

O site apresenta informações interativas sobre animais, incluindo:

- Navegação por abas
- Accordion FAQ
- Modal
- Tooltip
- Scroll suave
- Dropdown menu
- Menu mobile
- Animações ao scroll
- Slider customizado
- Sessão dinâmica de números carregada via JSON

O projeto foi posteriormente atualizado para utilizar **Vite** como bundler, permitindo ambiente moderno de desenvolvimento com hot reload e build otimizado.

Praticar:

- Manipulação avançada do DOM
